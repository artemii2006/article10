# Воспроизведение: машинное обучение для прогнозирования премий за риск облигаций

Репозиторий для воспроизведения результатов статьи о прогнозировании избыточной доходности
казначейских облигаций США с помощью методов машинного обучения (форвардные ставки + макропанель FRED-MD).

## Структура

```
data_raw/          — сырые скачанные файлы (кривые доходности, FRED-MD)
data_processed/    — очищенные датасеты (forward_rates.csv, excess_returns.csv, macro_panel.csv)
src/data/          — скрипты сборки данных
src/models/        — классы/функции моделей (по семействам)
src/eval/          — expanding window, R²_oos, тест Clark-West
notebooks/         — исследовательские ноутбуки
results/           — итоговые таблицы, графики
```

## Пайплайн

1. **Данные** (`src/data`): скачать доходности и FRED-MD в `data_raw/`, построить
   форвардные ставки, избыточные доходности и трансформированную макропанель в `data_processed/`.
2. **Модели** (`src/models`): реализации моделей, сгруппированные по семействам.
3. **Оценка** (`src/eval`): прогнозы вне выборки в схеме expanding window,
   расчёт R²_oos и тест Clark-West против бенчмарка (историческое среднее).
4. **Результаты** (`results/`): таблицы и графики.
